## Start the app

You need Node 24 and npm 11. From the repository root:

```sh
cd web
npm install
npm run dev
```

The app runs at `http://127.0.0.1:5199`.

## Walk the screens

The app uses hash routes, so each screen has its own address:

- `#/club` is the club page with the seat plan.
- `#/seat` is your seat, with your delegate's status.
- `#/brief` is where you write the brief.
- `#/vote` is a pending vote with the override window.
- `#/aireceipt` is the receipt for a delegate vote.
- `#/vault` is the vault, with the holder check.
- `#/sell` and `#/buy` are the sale screens.
- `#/receipt/vote`, `#/receipt/sale`, `#/receipt/buy`, and `#/receipt/vault` are the receipts.
- `#/states` lists the status tokens and edge states.
- `#/docs` is this site.

## Check the build

```sh
npm run build
```

The build runs the TypeScript check and then bundles the app.

## What you won't see

Buttons change screens. They don't sign transactions or read the chain. See [limitations](/docs/reference/limitations).
