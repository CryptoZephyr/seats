## What you see

The brief screen shows the brief's fingerprint, which is the hash stored on-chain for each seat you hold.

## What you do

Writing a brief from the browser isn't built yet. In the testnet runs, the brief text was held off-chain as an OutLayer secret and the contract stored only its hash.

## What the delegate uses it for

The delegate reads each proposal against the brief and writes a vote and a reason. It can't change the brief.

## How you know it worked

The fingerprint changes when you save a new brief. The old fingerprint still proves which brief an earlier vote used.

## If nothing changes

Check that the brief saved, then open the pending vote. If the vote still shows the old reason, it was prepared before your change. Override it inside the window if you want a different result.
