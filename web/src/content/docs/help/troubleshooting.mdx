## The page doesn't load

Check that you're running `npm run dev` from the `web` folder and opening `http://127.0.0.1:5199`.

## A route shows the club page

The route name is wrong. Use one of the hash routes listed in the [quickstart](/docs/get-started/quickstart).

## The vault says only holders can open it

You don't hold a seat, or the seat was sold. This is the intended refusal.

## The window says closed

The override window has passed. The vote is cast or about to be cast. Read the receipt.

## A vote change was refused

- "This account doesn't control this seat." Sign in with the account that controls the seat.
- "This vote is no longer waiting to be sent." Refresh the proposal. The vote may already be cast or canceled.
- "The time to change this vote has passed." The override window has closed. Read the vote status or receipt.
- "Your delegate's vote is already being sent." Wait for the cast status to update before trying again.
- "That vote choice isn't allowed." A vote can only be changed to Approve or Reject.

## The vote change couldn't be confirmed

A wallet timeout or network error can happen after a testnet transaction lands. Refresh the proposal and its change history before trying again.

## Change history couldn't be loaded

Choose retry to load FastNear transaction history again. The screen doesn't show an override badge unless the history confirms one.

## A screen says it couldn't read the chain

The read from the testnet RPC failed. Choose try again on the message. Every number on the functional screens comes from a live read, so nothing is shown until that read succeeds.
