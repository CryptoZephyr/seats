## Your brief

Your saved brief is encrypted in private storage outside the public testnet record. The service sends it to NEAR AI when your delegate prepares a vote. Don't put passwords, wallet keys, or other secrets in it.

The fixed delegate asks for no reasoning and refuses to send a vote receipt if reasoning is present. Older test votes made before this fix include brief text in public receipts. That text is public and can't be removed. Seats using older delegate code may not have the same protection.

## Public records

Anyone can read the seat owner, brief fingerprint, vote, one-line reason, proposal, and transaction records. The fingerprint does not reveal the saved brief by itself. A public vote receipt may contain more data, especially if it came from an older delegate.

## Vault content

The vault response is encrypted to a key created in your browser. Your browser decrypts it locally. The public transaction doesn't contain the vault text in plain form.

Read [who can act on a seat](/docs/security/permissions) before connecting a wallet.
