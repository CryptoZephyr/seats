## Wallet or network timeout

A wallet can time out after a transaction reaches testnet. Refresh the page and check the seat, proposal, or transaction record before trying again.

## Brief storage or fingerprint save

Private storage and the public fingerprint save are separate steps. If the page says the brief was stored and offers `Retry on-chain save`, retry that step only. Check the fingerprint before starting another save.

## Vote change after the deadline

The contract refuses a change after the deadline. The page shows the recorded vote and its receipt. You can't reopen the window.

## Failed sale or vault request

If a sale is declined or expires, the buyer is refunded and the seller keeps the seat. If a vault request fails, check the transaction and retry only after the page can read the current seat and cost.

## Missing public record

A transaction hash or history entry may take time to appear. Use the page's retry action. Don't guess a result from a loading screen.
