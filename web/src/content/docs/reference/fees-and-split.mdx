## Joining and minting

The current application bond is 0.1 NEAR. The club returns it when the application proposal is decided. After approval, minting your seat requires a 4.5 NEAR deposit. It funds your delegate, and almost all of it is returned after each vote.

## Vote costs

One recorded testnet vote cycle reduced the seat account by about 0.004 NEAR for the request and cast. This is a measured example, not a fixed price. The wallet shows the network fee before you sign.

## Sale split

When a sale completes, the seller receives 95% of the price and the club receives 5%. The app shows the amounts before you sign. If the sale does not complete, the buyer is refunded in full.

These are testnet amounts. Testnet NEAR has no real-world value.
