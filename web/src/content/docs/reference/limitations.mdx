## Testnet only

Seats has not launched on mainnet and has not had a full security audit. Testnet NEAR has no real-world value.

## Services can be slow or unavailable

The app reads NEAR testnet and sends wallet transactions. Saving a brief and preparing a vote also depends on the profile service and NEAR AI. If a service is asleep or a network request fails, check the on-screen status and transaction record before retrying.

## Brief privacy depends on delegate code

The fixed delegate stops if a response includes reasoning that could expose your brief. Older test votes made before that fix show brief text in public receipts. Seats that still use older delegate code may have different behavior. See [Data and privacy](/docs/security/data-and-privacy).

## Hardware check

Verified public OS on genuine Intel and NVIDIA hardware.

The hardware check doesn't prove which private software served a particular vote. A service can fail, and testnet evidence from one run doesn't prove every future run.
