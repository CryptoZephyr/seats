## What it shows

The contracts for the seat, the voter, and the TDX verifier are deployed on testnet, and the club DAO is live. The record in the repository lists the transaction hashes behind the runs.

## What it doesn't show

It doesn't show a live wallet flow, a live sign-in, or the web app connected to the contracts. Those aren't built in this repository.

## Where to check

Use the explorer links from the [deployment reference](/docs/reference/deployment). Each run's proof is in [verified examples](/docs/evidence/verified-examples).
